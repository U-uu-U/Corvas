# Corvas v1.6.0-beta.2

## 本版更新

- Flow Canvas 正式更名为 Corvas，名称由 Corvus 与 canvas 合成；同步应用界面、启动页、浏览器扩展、GitHub 仓库及后续安装包命名。
- 升级继续使用原数据目录、应用标识和 MCP 工具名；保留已有画板、对话、任务记录及 API 配置，macOS 保留旧钥匙串标识。
- 诊断日志集中到「设置 > API」最底部，不再出现在其他设置分类；保留刷新、复制诊断摘要及导出报告。
- 模型展示信息接入远端 CONFIG，支持模型名称、简要说明、线路分组、推荐标记和售价；价格包含币种、计价单位及来源，画布与 Agent 复用同一套解析。
- CONFIG 管理后台新增模型编辑表单和 JSON 编辑切换，支持草稿、发布、历史版本与回滚；优化发布栏布局，修复登录路由和 Linux 服务运行时路径。
- 内置模型名单与当前上架模型对齐，移除未接入模板，保留固定 30 秒双线路、独立可调时长线路和 HM 规格。
- 增加画布端上游错误映射，对图片、视频及文字请求使用统一提示，避免直接展示上游渠道、地址及敏感内容；保留提交结果不明、查询重试和任务 ID 恢复语义。
- 模型配置导出将参数与说明分离，方便后续维护；用户 API Key 不进入公开模型配置。

## 安装包

- `Corvas.Setup.1.6.0-beta.2.exe`：Windows x64 安装版。
- `Corvas.1.6.0-beta.2.exe`：Windows x64 便携版。
- `Corvas.1.6.0-beta.2.mac.universal.dmg`：macOS 通用安装包，支持 Apple Silicon 和 Intel。

Windows 与 macOS 使用同一份 `master` 提交，全部安装包就绪后公开 Release。
升级前退出旧应用；旧版本安装包名称保留，不改写历史发布文件。

本版为预发布，不替换现有稳定版；macOS 包未使用 Apple Developer 身份签名和公证。
模型配置可更新已支持协议下的参数与展示信息，新协议适配仍需客户端更新；展示售价不改变中转站实际扣费。
