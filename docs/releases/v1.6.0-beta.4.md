# Corvas v1.6.0-beta.4

## 本版更新

- 视频模型按推荐渠道、备用渠道分组，显示当前使用的模型；补全 Seedance 2.0 Fast、Mini、Pro 名称，支持新站与老站的同款展示和已确认价格。
- 新增 Seedance 2.5 Pro，完善 GlobalAiOpc、StarFrame 适配；停用渠道不再接受新任务，已有任务仍可恢复。
- 整合协作者的错误脱敏补丁，统一图片、视频、Agent 与素材审核错误提示；保留任务编号和诊断关联信息，避免上游响应原文直接出现在界面。
- 提交结果未知时明确提示优先恢复，避免重复生成；保留提交接口 404、过期下载地址刷新及签名视频下载的处理逻辑。
- 混元支持独立账号；完善 Rhino 启动、模型导入与可恢复整理流程，工作流可以通过 MCP 复用。
- 新增 Blender 工作台及画布音频播放控件，改进媒体标题编辑、连接显示和拖出素材操作。
- 本地素材访问使用持久化授权，API 配置使用系统加密；补齐生成和恢复产物的预览授权。
- 模型配置后台支持编辑视频时长和参考素材限制，并与客户端校验保持一致。

## 安装包

- `Corvas.Setup.1.6.0-beta.4.exe`：Windows x64 安装版。
- `Corvas.1.6.0-beta.4.exe`：Windows x64 便携版。
- `Corvas.1.6.0-beta.4.mac.universal.dmg`：macOS 通用安装包，支持 Apple Silicon 和 Intel。

Windows 和 macOS 安装包使用同一个主分支源码提交。升级沿用已有画板、素材、任务记录和 API 配置。

本版为预发布。安装包沿用现有未签名分发方式；macOS 包未进行 Apple 公证。
