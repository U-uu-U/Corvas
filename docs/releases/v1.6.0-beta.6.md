# Corvas v1.6.0-beta.6

## 本版更新

- 画布与侧栏模型列表只显示模型名称和能力参数，不再显示单价或未知费用。
- Agent 计划卡移除单价和预计费用展示，保留模型、数量、参数和执行操作。
- 同步新站视频模型的内部价格元数据，供 MCP 和 Agent 使用；老站价格保持原值。
- 保留现有渠道分组、当前模型提示、任务恢复和历史任务数据。

## 安装包

- `Corvas.Setup.1.6.0-beta.6.exe`：Windows x64 安装版。
- `Corvas.1.6.0-beta.6.exe`：Windows x64 便携版。
- `Corvas.1.6.0-beta.6.mac.universal.dmg`：macOS 通用安装包，支持 Apple Silicon 和 Intel。

两个平台使用同一个主分支源码提交。升级沿用已有画板、素材、任务记录和 API 配置。

本版为预发布，沿用未签名分发方式；macOS 包未进行 Apple 公证。
