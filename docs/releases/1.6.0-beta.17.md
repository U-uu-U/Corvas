# Corvas 1.6.0-beta.17

- 设置入口移到右下角应用菜单，位于 AI Agent 下方。
- 内置中转站入口支持个人站和企业站，直接使用原站登录、任务和预览页面；网页视频下载可关联回原画布节点。
- 补充 HM Seedance 2.0 Fast/Mini 和 Seedance 2.5 Super 的参数及参考素材适配。
- Agent 支持素材用途标注和真实引用胶囊，保留图片、视频和音频的引用顺序。
- 模型状态条可显示单次已确认的结果，整体健康状态仍保留样本不足提示。
- 画布左上角新增资源节省快捷开关。
- 保留 beta.16 的视频下载进度、Mac 数据恢复和在线更新修复。

Windows 安装版支持设置中获取新版本，下载完成后点击重启安装。Mac 为 universal DMG，尚未进行 Developer ID 签名和公证，下载后需手动替换应用。

内置浏览器使用原站页面和下载地址，本版没有启用服务器视频转存或自有存储桶缓存。网页下载无法唯一匹配任务时保留文件并打开文件位置，不自动关联到其他节点。
