# Corvas v1.6.0-beta.3

## 本版更新

- 图片、视频和音频统一支持提示词引用胶囊，按媒体类型独立编号；同一素材可重复引用，点击胶囊可逐个移除。
- 新增素材用途标注，可记录角色、旁白、动作参考等用途。标注随本地素材保存，素材库支持查看、编辑和搜索，后续生成与 Agent 自动携带标注。
- 素材标注默认收起，鼠标悬停时展开，输入时保持展开。素材过多时只在顶部素材栏横向滚动，提示词和参数栏保持固定；同步适配浅色、深色主题及窄窗口。
- 修复重复参考素材上传和上游新生成节点的引用匹配，保留素材顺序、来源节点与提示词草稿。
- 优化画布平移响应，去除素材卡片阴影，减少拖动时的卡顿。
- 改进肖像保护、版权及内容审核错误提示，保留任务失败状态和可恢复任务信息；客户端和诊断日志隐藏上游地址。
- 视频生成完成后，下载地址失效或暂时不可用时，按原任务 ID 重新查询地址并尝试下载，不重新提交生成任务。
- 避免图片模型误入文字与视觉请求；文本节点的生成、合并用途标识更清晰。

## 安装包

- `Corvas.Setup.1.6.0-beta.3.exe`：Windows x64 安装版。
- `Corvas.1.6.0-beta.3.exe`：Windows x64 便携版。
- `Corvas.1.6.0-beta.3.mac.universal.dmg`：macOS 通用安装包，支持 Apple Silicon 和 Intel。

Windows 和 macOS 安装包使用同一份源码提交。升级沿用已有画板、素材、任务记录和 API 配置。

本版为预发布。macOS 包沿用现有分发方式，未使用 Apple Developer 身份签名和公证。
