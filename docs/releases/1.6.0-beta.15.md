# Corvas 1.6.0-beta.15

- 设置中增加手动获取、下载和校验软件新版本。Windows 安装版由用户确认后重启安装；Mac 下载校验后打开 DMG；便携版打开下载位置。不会因启动 CONFIG 同步而自动安装软件。
- 启动画布立即检查远程 CONFIG，运行中每 10 秒检查，联网后补同步；设置显示 revision、最近同步时间和手动“立即同步”，失败保留已有配置。
- 后台明确完成视频任务后停止生成计时，显示“正在下载...”、下载字节数及速度；慢速持续传输不再被固定总时长打断。
- 修复视频控件默认参数在压缩构建后导致的 `s is not defined`，增加真实视频下载、落图、状态与隐私回归检查。
- 合并 PR #39 并补充成功结果统一过滤、旧缓存恢复地址过滤及前端本地结果保护。原任务查询、下载鉴权和用户参考素材不变。
- 包含 beta.14 的删除立即保存、分组删除记录同步、图片替换失败恢复原节点及 macOS 文件监听退出修复。

Windows x64 安装版/便携版和 Intel/Apple Silicon 通用 Mac DMG 从同一源提交构建。客户首次需要安装这一版，之后可以使用软件更新入口。Mac 沿用未签名/未公证分发方式。

本次不包含未完成的 Agent 素材改动，不变更中转站模型、计费或 CONFIG 发布内容；不增加跨重启的分段下载续传，也不自动重新提交已生成任务。
