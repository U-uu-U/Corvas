# Corvas 1.6.0-beta.18

- 修复 GitHub 限流导致在线更新失败的问题：版本检查、更新清单和安装包下载改用 RavenHash 自有站点。
- 更新连接遇到临时故障时自动尝试另一自有站点；Windows 使用完整安装包，保留 SHA-512 校验。
- 分别提示请求限流、网络超时、服务器故障、文件校验失败和本地写入错误，并保留结构化诊断记录。
- 保留 beta.17 的全部画布功能与修复。

beta.16/17 的更新地址已固化在旧客户端，首次迁移请手动覆盖安装本版，无需卸载或清空用户资料。之后可在设置中获取新版本。

Mac 为 universal DMG，尚未进行 Developer ID 签名和公证，下载后需手动替换应用。
