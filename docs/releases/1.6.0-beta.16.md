# Corvas 1.6.0-beta.16

- 设置中提供手动软件更新；启动立即同步 CONFIG，运行中每 10 秒检查，恢复联网后补同步，并显示当前配置版本。
- 视频后台完成后停止生成计时，显示“正在下载...”及下载大小/速度；慢速持续传输不再受固定总时长限制。
- 修复打包后视频落图的 `s is not defined`，补充旧缓存恢复时的上游地址过滤。
- 包含 Mac 文件监听退出、删除保存和图片替换失败保护修复。
- 修正测试版软件更新清单命名，保证 Windows 更新器能找到 beta 通道；beta.15 未公开，由本版取代。

Windows 安装版/便携版与 Intel/Apple Silicon 通用 Mac DMG 使用相同源码提交。首次安装这一版后可使用软件更新入口；Mac 下载校验后由用户打开 DMG 替换应用，不做静默安装。保留现有用户数据和 API 设置。

本次没有变更中转站计费或模型配置，也没有新增自动重新生成、跨重启分段下载续传。
