# Corvas 1.6.0-beta.19

- 新增 HTTP MCP 接入。画布打开后显示 20 秒连接提示，可复制地址或配置到本机 Harness；设置中的开关可持久保存。
- 自动上画布只接受图片、视频和音频，排除文档、设计源文件、临时文件和空文件；启动和切组清理已确认失效的素材记录，保留断盘或权限异常素材的重接入口。
- 开屏期间预加载画布内容，至少显示 2 秒、最多 7 秒；右下角显示版本号。
- 生图站、视频站和企业站支持登录后联动画布账户，保留手动 API 配置；外部 MCP 和诊断入口移到创作设置。
- 修复右键轻微抖动时无法打开节点菜单，调整菜单主题和节点辨识。
- 修复部分渠道的无扩展名视频下载地址识别，补齐生图站 Seedance 视频端点适配。

Windows 安装版可在设置中获取更新。Mac 为 universal DMG，仍需下载后手动替换应用；本版未进行 Developer ID 签名和公证。
