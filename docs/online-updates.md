# Online Updates

设置新增“软件更新”页，点击“获取新版本”后检查并下载可用更新。窗口显示当前/新版本、进度、更新内容，支持取消和重试。不会在应用启动或退出时偷偷下载安装。

- Windows 安装版使用 `electron-updater` 的 NSIS 更新流程。下载完成后由用户点击“重启并安装”，先保存画布，存在运行中的生成或 Agent 任务时拒绝退出。用户数据和 API 配置目录不属于安装包替换范围。
- macOS 当前没有 Developer ID 签名/公证，因此采用在线下载、校验并打开 DMG，由用户完成应用替换，不宣称静默更新。以后有签名证书和 ZIP 更新产物时可改用 MacUpdater。
- Windows 便携版下载相同类型的新 EXE 并打开下载位置，用户退出旧版后替换；不把便携版静默改成安装版。
- 源码运行只检查版本，不覆盖源码。Linux 暂不提供安装更新。

更新源使用自有发布服务：优先 `https://cart.ravenhash.org/corvas/api/updates`，网络或临时 HTTP 失败时尝试 `https://art.ravenhash.org/corvas/api/updates`。两个域名目前共享发布后端，不是独立存储备份。客户端不再请求 GitHub 更新清单或下载地址，不发送生成 API Key、网站登录 Cookie 或 GitHub 凭据。缺少任一平台安装包的发布，以及降级版本不展示。测试版允许更新至更新的测试版/正式版，正式版不主动切换到测试版。版本比较使用 semver。

Windows 安装版使用标准 NSIS 更新器，从自有版本目录读取 `beta.yml` / `latest.yml` 并完整下载安装包，关闭增量下载。清单中的版本、文件名、大小和 SHA-512 必须与版本查询结果一致。Mac/便携版使用自有发布清单的 SHA-256 和精确字节数校验，只有校验完成的文件可打开；禁止不可信域名、非 HTTPS 重定向和超出大小上限的下载。

2026-10-08：真实 beta.16 更新器读取 GitHub 清单时复现 HTTP 429 secondary rate limit，原界面统一显示“下载或校验失败”。新版分别显示限流、连接超时、服务器错误、文件校验失败、磁盘空间和目录权限问题，并把错误类别、HTTP 状态及阶段写入 `app.update_error` 诊断记录，不记录响应原文。beta.16/17 的地址写死在客户端，首次迁移需要手动覆盖安装包含本修复的新版。

## Release Pipeline

两平台构建验证后生成 `build-info-windows.json` / `build-info-macos.json`，记录版本、源提交及资产 SHA-256。GitHub Actions 将安装包、更新 YAML、blockmap 和来源记录上传到同一草稿；只有两平台产物齐全、来源提交一致、上传文件校验值吻合时，才自动公开该 tag 对应的 Release。新 tag 仍须在用户明确要求发布时创建。

GitHub 是构建和发行存档入口。发行流程还必须用 `scripts/deploy-release-page.py` 将已校验的双平台产物同步到自有发布服务，之后新版客户端才会发现更新。部署时同时计算 SHA-512；已有版本只允许补齐缺失校验字段，不能替换文件、来源提交或更新说明。服务端使用 JSON（兼容 YAML）生成 Windows 更新清单。

`node scripts/app-update-live-smoke.cjs --live` 使用隔离用户目录和真正的 NSIS 更新器，完整下载线上最新 Windows 包并同时校验 SHA-256/SHA-512，断言所有请求均使用自有域名；不会安装或退出用户正在使用的画布。`FLOW_LIVE_UPDATE_CURRENT` 指定模拟的旧版本，`FLOW_LIVE_UPDATE_ASAR` 可指定待测打包代码。

第一次需要安装包含本功能的新版；早先已安装的版本无法仅靠 CONFIG 增加主进程更新器。尚未公开的草稿不会被“获取新版本”选中。

## CONFIG 自动同步（2026-10-06）

软件安装与模型配置同步是两个独立流程。打开画布时先显示已验证缓存，再立即检查远程 CONFIG，即使缓存刚更新也检查一次；不等待网络才打开画布。正常运行继续由主进程心跳每 10 秒检查，联网恢复时立即重试，重复启动和手动点击复用同一在途请求。显式清空 CONFIG 地址的旧设置仍保持关闭。

设置 → 软件更新增加“模型配置 CONFIG”区域，显示当前生效 revision、模型数量、最近成功同步时间、自动同步周期及错误；“立即同步”可以手动强制拉取。该按钮不会下载软件安装包。配置请求的 15 秒超时覆盖响应头和正文读取，正文逐块限制为 2 MiB，失败或 schema 校验不通过继续使用已有配置，不清空模型和 API 设置。

已验证：45 项模型配置和更新器定向测试；隔离 Electron 设置流程覆盖启动、定时检查、带新缓存重新加载、离线保留、联网恢复、手动同步及软件更新下载/取消/重试/显式安装。测试使用本地 CONFIG 和模拟安装器，不执行真实安装。

网站和客户端更新以同一自有发布清单为准。“暂无可安装的新版本”表示清单中没有比当前版本更高、且符合当前平台和测试版策略的完整发布；仅构建本地文件或上传 GitHub 不代表自有更新源已切换。

常规自动化测试使用隔离用户配置和模拟下载，显式的 live 验证会下载真实安装包；两者都不执行真实安装或退出用户正在使用的 Corvas。只有发布任务才创建 release tag 和打包。
