# Agent 素材标注与引用胶囊

画布 Agent 可通过现有画板事务完成两类操作，无须操作DOM：

- `node.update` 的 `patch.referenceAnnotation`：写入当前素材节点的用途标注，最多80个字符，空字符串清除。标注保存在原项目，不修改素材文件。
- `node.set-prompt` 的 `promptParts`：按顺序传入 `{text: "提示词片段"}` 与 `{sourceNodeId: "素材节点ID"}`，由系统创建真实引用胶囊。素材必须先通过非history连线连接到目标图片/视频生成节点；可在同一事务中先建节点、连线再引用，也可重复引用同一素材。

胶囊ID、文本偏移、连接ID和上传编号由系统计算；不需要Agent拼写底层citation字段。引用失联或参数无效时整个事务回滚，操作可整体撤销。图、视频和音频按各自上传次序编号。

素材搜索及读取结果包含用途标注，搜索也支持标注文本。Agent生成计划采用当前节点的引用字段，旧任务入口快照不能覆盖新创建的胶囊；结果保留当前原始提示词及引用草稿，便于再次打开和复用。标注变化会使尚未执行的旧计划失效，避免按旧用途提交。显式清空的标注不会被素材库旧缓存再次填回。

验证：214项相关单元测试通过，隔离Electron模拟Agent工具调用验证标注、真实胶囊、多次引用、按标注搜索及页面刷新保留；生成请求的标注和上传顺序由mock回归覆盖，没有提交收费生成。截图 `output/playwright/agent-material-citations.png`。需要正常重启源码版，让主进程Agent工具加载新契约。
